# Panel deployment notes

1. Rotate the MariaDB credential previously committed in `panel/src/lib/db.ts`; Git history still contains it. Put the replacement in private deployment configuration, not source control.
2. Configure `panel/.env.local` from `panel/.env.example`. All five `DB_*` values are required. Configure the public brand, connect address and Discord URL as desired. `SESSION_SECRET` is documented for deployment compatibility; session token generation itself uses cryptographic randomness.
3. Install dependencies with `cd panel && npm ci`; run `npm test`, `npx tsc --noEmit`, and `npm run build`.
   On an isolated MariaDB test instance, set `PANEL_TEST_DB_SOCKET` to its `/tmp/newrpg-panel-db.*` socket and `PANEL_TEST_DB_NAME` to a `panel_test*` schema, then run `node scripts/test-schema-contract.mjs` and `node scripts/test-db-invariants.mjs`. Run `npm run test:e2e` after building; `PANEL_E2E_PROFILE_SLUG` selects a public-profile fixture. The browser host needs Playwright's Chromium system libraries.
4. Apply the repository migrations to the selected MariaDB database. `sql/65-panel-schema.sql` creates panel tables; v66 removes the unused PIN table, adds the poll integrity key and creates `panel_runtime_snapshot`; v67 adds the action queue and extends the sanction action enum. `scripts/apply-migrations.sh` strips historical hardcoded `USE` statements during import while preserving checksums. Back up data before new migrations. If v65 was imported manually, verify all its tables before baselining its checksum in `schema_migrations`.
5. Start the `sunset_panel_bridge` FiveM resource after v67, then verify `panel_runtime_snapshot.updated_at` advances. If it does not, the panel correctly reports the server offline. Test a low-risk staff queue action on staging and verify pending → processing → completed/failed. There is no `127.0.0.1:30121` HTTP service.
6. Bind Next.js to loopback behind an HTTPS reverse proxy. Set `PANEL_PUBLIC_ORIGIN` to the public HTTPS origin. Set `PANEL_TRUST_PROXY=1` only if that proxy overwrites `X-Real-IP` and preserves the public `Host` and `Origin`. Add proxy-side login rate limiting. Do not forward arbitrary client-supplied proxy headers. Restart the panel process after replacing its build.

Do not treat the staff UI as production-verified moderation until the FiveM consumer has been observed executing actions correctly. The seeded v65 mayor poll is removed by v66 only if it has no votes. A poll with real votes is intentionally retained for manual review rather than deleting voter data.
