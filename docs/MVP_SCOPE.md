# MVP scope

Included:

- Username/password registration and login.
- One account = one player, automatic profile, sex/model mapping.
- Identifier observation as security metadata.
- Session/history/duplicate-login/reconnect cleanup.
- Configurable first-login cinematic and deterministic LSIA spawn.
- Custom global chat, history, styles, rate limits, central commands.
- Staff hierarchy, required MVP commands, sanctions and DB audit.
- Base level/XP/playtime/login statistics.
- RPC, NUI focus, structured logs, migrations, diagnostics, tests.
- Pinned `bob74_ipl` map-hole/interior infrastructure.

Explicitly excluded: economy/money, items/inventory, jobs, factions, owned vehicles, housing, businesses, phone, police/crime gameplay, licenses, quests, casino, crafting, clans, turfs, character slots, appearance editor, and anti-cheat product features.

The product is complete only when the included flow passes the manual checklist on a real FiveM client. Headless tests cannot establish visual or multiplayer runtime stability by themselves.
