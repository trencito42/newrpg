# Localization glossary

| Concept / internal ID | English | Romanian | Notes |
|---|---|---|---|
| property | Property | Proprietate | Use “casă” only when the object is explicitly a house. |
| home spawn | Home spawn | Locuință principală | The selected property used as spawn. |
| tenant | Tenant | Chiriaș | Do not alternate with “renter” / “locatar”. |
| rent | Rent | Chirie | Verb: “a închiria”. |
| vehicle | Vehicle | Vehicul | “Mașină” only in informal prose. |
| cash | Cash | Bani în numerar | Keep distinct from bank balance. |
| faction | Faction | Facțiune | Internal faction IDs never change. |
| clan | Clan | Clan | Player-created clan names stay unchanged. |
| rank | Rank | Rang | “Grad” is reserved for police/medical grades when appropriate. |
| on duty | On duty | În serviciu | Off duty: “în afara serviciului”. |
| payday | Payday | Payday | Established server term; keep consistently. |
| impound | Impound | Parc auto | “Confiscat” describes vehicle status. |
| wanted level | Wanted level | Nivel de urmărire | Never translate the stored numeric/state value. |
| server ID | Server ID | ID server | Command arguments use the same numeric ID. |
| Blaze Points | Blaze Points | Puncte Blaze | Product currency name. |

Canonical command names (`/f`, `/d`, `/r`, `/sethome`, and others) remain unchanged. Translate only their description, usage, errors, and success messages.
